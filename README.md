## ทีมงาน

| ไฟล์ (`.claude/agents/`) | ตำแหน่ง | ส่งงานให้เมื่อ |
|---|---|---|
| `contract-reviewer.md` | ผู้ช่วยตรวจสัญญา | ตรวจ/redline สัญญาเชิงพาณิชย์ |
| `matter-doc-prep.md` | ผู้ช่วยเตรียมเอกสารประจำงาน | สร้างโฟลเดอร์ใน Drive, คัดลอกไฟล์, ดาวน์โหลด/กรอกแบบฟอร์ม |
| `litigation-lead.md` | ทนายผู้รับผิดชอบคดี | วางรูปคดี ฟ้อง/ถูกฟ้อง ประเมินคดี |
| `devils-advocate.md` | เอเจนต์วิเคราะห์ฝ่ายตรงข้าม | โจมตีรูปคดีเพื่อหาจุดอ่อน (ทำงานคู่กับทนายคดี) |
| `demand-letter.md` | ผู้ช่วยร่างหนังสือทวงถาม | ร่างหนังสือทวงหนี้ ครั้งแรก / Final Notice |
| `senior-counsel.md` | ที่ปรึกษากฎหมายอาวุโส | ความเห็นเชิงธุรกิจ, compliance, อาญา, การค้าระหว่างประเทศ, เรื่องทั่วไป |
| `hr-legal.md` | นิติกรอาวุโสด้านแรงงานและงานบุคคล | เอกสาร HR, วินัย, เลิกจ้าง, พนักงานตรวจแรงงาน |

กฎการมอบหมายงานทั้งหมด (รวมกรณีก้ำกึ่ง และ workflow ที่ใช้หลาย agent) อยู่ใน `CLAUDE.md`

## วิธีใช้งาน

1. เปิดเซสชัน Claude Code ใหม่บน repository นี้ (บน claude.ai/code เลือก repo นี้ หรือบนเครื่องรัน `claude` ในโฟลเดอร์นี้)
   ระบบจะโหลด `CLAUDE.md` (เจสัน) และ agent ทั้ง 7 ตัวให้อัตโนมัติ
2. สั่งงานเจสันเป็นภาษาปกติ แนบไฟล์ได้ เช่น
   - "ช่วยตรวจสัญญาเช่าโกดังฉบับนี้หน่อย" → ผู้ช่วยตรวจสัญญา
   - "ลูกค้า ABC ค้างค่าขนส่ง 350,000 บาท ทำหนังสือทวงให้หน่อย" → ผู้ช่วยร่างหนังสือทวงถาม
   - "เราโดนลูกค้าฟ้อง ประเมินคดีให้หน่อย" → ทนายคดี ⇄ ฝ่ายตรงข้าม (วงจรสร้างรูปคดีและโจมตี)
   - "พรุ่งนี้ต้องไปพบพนักงานตรวจแรงงาน เตรียมเอกสารให้หน่อย" → HR-Legal + ผู้ช่วยเตรียมเอกสาร
3. ถ้า agent ต้องการข้อมูลเพิ่มหรือต้องขออนุมัติ เจสันจะถามคุณแทน แล้วส่งคำตอบกลับให้ agent ทำต่อ
4. เจสันรายงานผลตามรูปแบบ "📋 รายงานจากเจสัน" และบันทึกผลงานไว้ที่ `outputs/`

ถามเจสันได้เสมอว่า "ทีมมีใครบ้าง" หรือ "งานนี้ส่งให้ใคร"

## การแก้ไข / เพิ่ม agent

- แก้หน้าที่ของ agent: แก้ไฟล์ใน `.claude/agents/` (ส่วน `description` ด้านบนสุดคือคำอธิบายหน้าที่)
- เพิ่ม agent ใหม่: สร้างไฟล์ `.md` ใหม่ใน `.claude/agents/` ตามรูปแบบเดิม แล้วเพิ่มชื่อในตารางข้อ 3–4 ของ `CLAUDE.md`
- ทุกไฟล์ agent มีส่วนท้าย **"การทำงานภายใต้เจสัน"** ซึ่งกำหนดวิธีส่งงานกลับ (สถานะ: รอข้อมูลจากผู้ใช้ / เสร็จสมบูรณ์ / นอกขอบเขต) — ควรคงส่วนนี้ไว้
- การแก้ไขมีผลในเซสชันถัดไป

## ข้อควรรู้

- **ความลับ:** `outputs/` อยู่ใน `.gitignore` — ห้าม commit เอกสารลูกความหรือข้อมูลคดีขึ้น git เพราะ repository นี้เก็บเฉพาะ "ตัวระบบ" ไม่ใช่ข้อมูลงาน
- **เซสชันบนคลาวด์เป็นเครื่องชั่วคราว** — ไฟล์ใน `outputs/` จะหายเมื่อเซสชันจบ ถ้าต้องเก็บ ให้สั่งเจสันบันทึกเข้า Google Drive (ผ่านผู้ช่วยเตรียมเอกสาร)
- **เครื่องมือค้นกฎหมายไทย:** prompt ของทนายคดีและ HR-Legal อ้างถึง "ไฮเซนเบิร์ก" (Thai legal research MCP) ซึ่งตอนนี้ยังไม่ได้เชื่อมต่อ — ระหว่างนี้ agent จะระบุ `[ต้องตรวจสอบ]` แทนการอ้างมาตรา/ฎีกาจากความจำ
- **Knowledge Base / แม่แบบ / หัวจดหมาย:** agent บางตัวอ้างถึงไฟล์เหล่านี้ (เช่น บันทึก carrier vs. agent, ข้อบังคับบริษัท, หัวจดหมายแต่ละบริษัท) ซึ่งยังไม่มีใน repo — แนบให้เจสันเมื่อสั่งงาน หรือเก็บใน Google Drive แล้วบอกตำแหน่ง
- **Google Drive:** ผู้ช่วยเตรียมเอกสารต้องใช้ Google Drive connector ที่เชื่อมไว้ในบัญชี
- **ทุกผลงานเป็นร่าง** ต้องผ่านการตรวจทานโดยทนายความก่อนใช้จริงเสมอ
